# AI 工具导航

一个收集各种 AI 工具的导航网站，支持搜索、分类筛选、收藏和深浅色模式，无需登录注册，打开即用。

## 在线访问

https://heiye-888.github.io/ai-tool-navigation/

## 功能

- 收录 232 款国内外主流 AI 工具
- 按对话、图像、视频、音频、编程、办公、搜索、设计、Agent、学习分类浏览
- 关键词搜索与标签筛选
- 收藏工具、查看详情
- 深浅色模式
- 顶部导航可跳转「黑叶插件」页面

## 使用

直接用浏览器打开 `index.html` 即可，也可以部署到 GitHub Pages、Netlify、Vercel 等静态托管平台。

# 黑叶插件

黑叶团队开发的 CorelDRAW 增效插件，插件中心页面：`plugins.html`。

## 黑叶CDR工具箱

集成在 CorelDRAW 中的多功能工具箱插件：在 CDR 工具栏调出「黑叶工具箱」窗口，一键转曲、AI 抠图、批量导图、文字识别、透视矫正等 20+ 工具随点随用。

- **兼容版本**：CorelDRAW 2017 - 2026
- **当前版本**：v0.1.12
- **安装方式**：下载安装包后双击运行，按提示一键安装

## 下载安装包

安装包存放于百度网盘：

- 网盘链接：https://pan.baidu.com/s/1FD-MeUVDxMDrAuPevevMOQ
- 提取码：mes4

打开网盘链接后输入提取码 `mes4`，即可下载「黑叶插件一键安装.exe」。
